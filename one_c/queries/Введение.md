## Основные концепции
При создании конфигурации разработчи не использует язык запросов. Все таблицы базы данных создаются и изменяются
платформой на основании метаданных конфигурации. Для редактирования (изменения, создания) данных в платформе 
используется объектная модель. А для чтения данных из базы в платформе реализована возможность использования языка
запросов, являющегося вариацией языка SQL.
