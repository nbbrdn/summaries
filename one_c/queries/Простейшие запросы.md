## Простейшие запросы

### Виды сравнения
* `=` - равно
* `<` - меньше
* `>` - больше
* `<>` - не равно
* `>=` - больше или равно
* `<=` - меньше или равно
* `В` - определяет входит ли значение в список значений
* `МЕЖДУ` - проверка вхождения значения в определенный интервал
* `В ИЕРАРХИИ` - позволяет отобрать все элементы, подчиненные группе или элементу
* `ПОДОБНО` - используется только для сравнения строковых значений. Проверка соответствия строки определенному шаблону
* `ЕСТЬ NULL` - проверка, является ли значение слева NULL
* `ССЫЛКА` - используется только для ссылочных типов. Проверка на то, что ссылка относится к определенному типу.

#### Служебные символы для шаблонов ПОДОБНО
* `%` (процент) - последовательность, содержащая любое количество произвольных символов
* `_` (подчеркивание) - один произвольный символ
* `[...]` (в квадратных скобках один или несколько символов) - любой одиночный символ из перечисленных внутри квадратных скобок. В перечислении могут встречаться диапазоны, например a-z, означающие произвольный символ, входящий в диапазон, включая концы диапазона.
* `[^...]` (в квадратных скобках знак отрицания, за которым следует один или несколько симвлов) - любой одиночный символ, кроме тех, которые перечислены следом за значком отрицания. 

#### Примеры запросов со сравнениями
```sql
ВЫБРАТЬ
	Фамилия,
	Имя,
	Отчество,
	ДатаРождения,
	Код
ИЗ
	Справочник.ФизическиеЛица
ГДЕ
	Код В ("000000001", "000000002", "000000003")
```
```sql
ВЫБРАТЬ
	Фамилия,
	Имя,
	Отчество,
	ДатаРождения,
	Код
ИЗ
	Справочник.ФизическиеЛица
ГДЕ
	ДатаРождения МЕЖДУ ДАТАВРЕМЯ(1800, 1, 1) И ДАТАВРЕМЯ(1810, 12, 31)
```
*Примечание*: Границы диапазона в условии МЕЖДУ задаются включительно.

```sql
ВЫБРАТЬ
	Ссылка
ИЗ
	Справочник.ШтатноеРасписание
ГДЕ
	Ссылка В ИЕРАРХИИ (&РуководительСсылка)
```
*Примечание*: Параметр условия `В ИЕРАРХИИ` также будет выведен в результатах запроса.
```sql
ВЫБРАТЬ
	Ссылка,
	Должность
ИЗ
	Справочник.Сотрудники
ГДЕ
	Должность ПОДОБНО "%редактор%"
```
*Примечание*: Сравнение строк в запросах осуществляется без учета регистра.

*Примечание*: Запрос с использованием оператора сравнения `ПОДОБНО` работает очень медленно.
