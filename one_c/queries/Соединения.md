ДАТА: 2026-02-22

## ИСТОЧНИКИ:

## Виды соединений
* Левое соединение
* Правое соединение
* Внутреннее соединение
* Полное соединение
* Соединение без условий

Соединение без условий - каждая строка левой таблицы соединяется с каждой строкой правой таблицы (общее результирующее количество строк равно произведению количества строк в левой талице на количество строк в правой таблице).

## Особенности работы с NULL
`NULL` - это специальный служебный тип, означающий остутствие какого-либо значения. В запросах 1С значения такого типа могут быть получены только присоединением, в случае когда для записи одной таблицы не найдены записи другой таблицы по условиям соединения.

Сравнение любого значения с `NULL` всегда возвращает `NULL`, а не `Истина` или `Ложь` (даже сравнение `NULL` и `NULL`).

Для проверки на `NULL` нужно использовать не сравнение, а специальный оператор `ЕСТЬ NULL`.

C `NULL` возможно выполнение любых арифметических операций, но их результат также всегда будет `NULL`.

В случае, когда вместо `NULL` нужно получить какие-либо другое значение, используется функция `ЕстьNULL`.
```
ЕстьNULL(ОстаткиОтпусков.Сотрудник, "Нет данных") КАК Сотрудник
```
Еще одна особенность - значения `NULL` игнорируются в агрегатных функциях.
